# Sala do Futuro for Pop!_OS COSMIC

Um aplicativo web nativo (PWA empacotada) para acessar a **Sala do Futuro** no Pop!_OS com ambiente COSMIC.

## Funcionalidades

- 🌐 Acesso direto à Sala do Futuro sem barras de navegador.
- 🔔 Notificações integradas ao sistema.
- 🖼️ Ícone dedicado no painel e menu de aplicativos.
- 🚀 Roda em segundo plano otimizado.

## Instalação

### Opção 1: Via Pacote .deb (Recomendado)

1. Baixe o último release na aba [Releases](../../releases).
2. Instale com:
   ```bash
   sudo apt install ./sala-do-futuro_1.0.0_amd64.deb
